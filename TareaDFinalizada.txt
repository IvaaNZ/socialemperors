RESUMEN
-------
El juego ya puede funcionar en español neutro. El idioma sigue siendo GLOBAL
(el mismo para todos los jugadores) y se elige al arrancar el servidor.
Por defecto sigue en portugués, así que nada cambia si no se configura.

Para jugar en español (Windows, PowerShell):
    $env:SOCIAL_EMPIRES_LANGUAGE = "es"
    .venv\Scripts\python server.py
En Git Bash / Linux:
    SOCIAL_EMPIRES_LANGUAGE=es .venv/Scripts/python server.py
Luego recargar la pestaña del juego con Ctrl+F5.
Valores aceptados: pt-BR (por defecto) o es. Cualquier otro valor frena el
arranque con un mensaje de error claro.

2. CAMBIOS DE CÓDIGO
--------------------
localization.py
  - Nuevo SUPPORTED_LOCALES = ('pt-BR', 'es').
  - normalize_locale() reconoce es, ES, es-AR, es_419, etc. -> 'es'.
  - load_catalog(idioma) carga {idioma}-core.json, -interface.json, etc.
    (antes estaba fijo en pt-BR).

get_game_config.py
  - El config traducido se cachea por idioma (antes solo existía el de pt-BR).

swf_localization.py
  - load_swf_catalog(idioma) y localize_swf(..., language=...) aceptan el idioma.

server.py
  - Nueva variable de entorno SOCIAL_EMPIRES_LANGUAGE (pt-BR por defecto),
    validada al arrancar.
  - get_game_config.php y el SWF servido usan ese idioma.
  - portuguese_game_movie() pasó a llamarse localized_game_movie().

El motor del juego sigue usando el config original en inglés: solo cambian
los textos visibles. IDs, precios, imágenes y reglas no se tocan.
