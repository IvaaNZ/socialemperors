A. Dejarlo andando

Clonar https://github.com/Jandersu/socialemperors en /e.
Crear el entorno virtual e instalar los paquetes (pip install -r requirements.txt).
Crear la cuenta de administrador con flask --app server create-admin y anotar usuario y contraseña.
Prender el servidor (python server.py) y entrar desde Chrome en http://127.0.0.1:5050/.
Si faltan archivos de arte (errores 404), copiarlos desde el paquete de la versión alpha 0.04a.
Comprobar qué versión tenés (git log -1 y git describe --tags --always).
